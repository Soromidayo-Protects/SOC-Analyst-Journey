## Troubleshooting: agent disconnection
- After restarting both VMs, the Wazuh dashboard showed Kali-lab as 
  **disconnected**
- Diagnosed the cause: the Wazuh manager's IP address changes on reboot 
  (dynamic IP), but the agent's config (`ossec.conf`) still pointed to the 
  old IP
- Attempted to fix by editing `/var/ossec/etc/ossec.conf` and updating the 
  `<address>` field under `<server>` to the manager's current IP
- Ran into a typo on the first attempt (accidentally truncated the IP), 
  corrected it, then restarted the agent:
  - `sudo systemctl restart wazuh-agent`
- Confirmed via logs that all agent components restarted cleanly 
  (wazuh-execd, wazuh-agentd, wazuh-syscheckd, wazuh-logcollector, wazuh-modulesd)

## Key takeaway
Dynamic IP addressing is a real operational annoyance in home lab setups, 
every VM restart can silently break agent connectivity. This is a genuine 
argument for setting a **static IP** on the Wazuh manager going forward, 
so agents don't need reconfiguring every session.
