# SOC Analyst Journey

Hands on cybersecurity training and home lab projects, built around the 
NIST Cybersecurity Framework (CSF) 2.0. Each project below maps to one of 
the six CSF functions, reflecting how real security teams organize their work.

## About this repo
I'm building practical, demonstrable skills for a SOC Analyst role through 
a self-directed home lab, not just learning tools, but applying them with 
purpose. Every entry documents what I did, what I found, and why it matters.
